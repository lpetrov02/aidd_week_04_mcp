# TODO — демо-приложение для лекции по MCP

Веб-приложение на Flask: UI на `/` и REST API на `/api/...`. Хранилище — JSON-файл с HMAC-подписью.
Python 3.9+, единственная зависимость — Flask.

## Установка и запуск

Все команды — из папки `week_04_mcp/apps`.

```bash
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m todo.web                  # http://127.0.0.1:5000 ; опции: --port 5000 --db todo_db.json
python -m unittest discover -s todo/tests -t .       # тесты
```

UI опрашивает API раз в 2 секунды, поэтому изменения, сделанные агентом, появляются на странице сами.

## API

| Метод и путь | Назначение |
|---|---|
| `GET /api/tasks[?done=true\|false]` | список задач |
| `POST /api/tasks` `{title, priority?, due?}` | создать (201) |
| `GET /api/tasks/{id}` | одна задача |
| `PATCH /api/tasks/{id}` `{title?, priority?, due?, done?}` | изменить указанные поля |
| `POST /api/tasks/{id}/complete` | отметить выполненной (идемпотентно) |
| `DELETE /api/tasks/{id}` | удалить задачу (200), повторно — 404 |

Ошибки — JSON `{"error": "..."}`: 400 (невалидный ввод), 404, 500 (БД не прошла проверку целостности).

## Подтверждение удаления

Приложение удаляет сразу и ничего не спрашивает: `DELETE /api/tasks/{id}` удаляет задачу, кнопка «Удалить» в UI тоже.
Подтверждение живёт в MCP-сервере: tool `delete_task` через Elicitation спрашивает пользователя и только после согласия вызывает `DELETE`.
Само HTTP-API не аутентифицировано. Считаем, что агент ходит в приложение только через MCP-tools,
а прямые запросы (`curl` и т. п.) ему запрещены настройками агента.

## Защита файла БД

`todo_db.json` хранит `{"payload": ..., "sig": HMAC-SHA256}`. Ключ лежит вне проекта: `TODO_SECRET_KEY`
или `~/.todo_demo/secret.key` (создаётся при первом запуске, права 0600). Любая правка файла «снаружи» ломает подпись:
приложение отвечает 500 «проверка целостности не пройдена», **ничего не перезаписывает** и не стартует с пустой базой.
Это защита от подделки, не шифрование (содержимое читаемо). Откат на старую валидную копию не ловится.
Агент, которому разрешено читать `~/.todo_demo`, ключ получить может: запретите ему этот путь.

## Устройство
- `todo/store.py` — подписанное JSON-хранилище, атомарная запись.
- `todo/service.py` — `TodoService`: вся логика и валидация (на неё ляжет MCP).
- `todo/web.py` — Flask: API и страница. `todo/templates/index.html` — UI.

## Контракт `add_task(title, priority="normal", due=None)`
- название: пробелы по краям обрезаются; пустое, пробельное, `None`, не-строка, длиннее 200 символов → `ValueError`;
- `priority` ∈ `low|normal|high`; `due` — дата `YYYY-MM-DD` (или пусто/`None`), несуществующая дата → ошибка;
- при ошибке состояние и файл не меняются; дубликаты названий разрешены; id не переиспользуются;
- `edit_task` меняет только переданные поля, всё валидируется до записи.

## Связь с лекцией
| Концепт MCP | Что брать из приложения |
|---|---|
| Tools | `add_task`, `edit_task`, `complete_task`, `delete_task` |
| Resources | `GET /api/tasks` → `todo://tasks`, `todo://tasks/{id}` |
| Prompts | `plan_day(date)` поверх открытых задач с полем `due` |
| Elicitation | `ctx.elicit` в `delete_task`: подтверждение перед удалением |
